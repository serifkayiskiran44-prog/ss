# M153 — Tedarikçi maliyet izleme

Issue #191 teslimatı: XML/Excel/manual kaynak snapshot’larını kültür güvenli biçimde karşılaştıran yerel maliyet izleme çekirdeği.

- Tutar/yüzde farkı, ayarlanabilir artış-azalış uyarısı, stale durumu ve kaynak/ürün/marka/kategori filtreleri eklendi.
- Çoklu tedarikçi snapshot’ları doğal olarak yan yana sorgulanabilir; batch async/cancel sözleşmesi var.
- Fiyat policy yalnız read-only bağlamdır; otomatik repricing ve canlı write yoktur.
