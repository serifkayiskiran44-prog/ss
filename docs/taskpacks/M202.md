# M202 — Etsy karşılaştırmalı gap audit

Issue #240 teslimatı: yerel Etsy yüzeyinin official-only capability manifest’i.

Kanıt: [Etsy request standards](https://developers.etsy.com/documentation/essentials/requests/), [Etsy inventory migration](https://developers.etsy.com/documentation/tutorials/inventory-shipping-migration/), [Etsy listings tutorial](https://developers.etsy.com/documentation/tutorials/listings/) ve read-only incelenen [DColl/etsy-mcp-server](https://github.com/DColl/etsy-mcp-server). Üçüncü taraf kodu kopyalanmadı.

- Local `EtsyShopClient` mevcut shop-scoped listing read ve explicit preview-gated write yüzeyleriyle karşılaştırıldı.
- Etsy’nin `includes=Inventory` migration’ına göre dedicated `/v3/application/listings/{listing_id}/inventory` yolu manifest’e eklendi; legacy includes yolu kabul edilmez.
- Official manifest listing/orders read, listing update preview-only ve image write blocked durumlarını; operation/scope/path/evidence ile gösterir. `EtsyReadinessService` bu matrisi raporlar.
- Eksik `docs/FULL-PARITY-ACCELERATION-2026-09-11.md` referansı mevcut checkout’ta bulunamadı; uydurulmadı. `docs/ETSY-HAZIR-KOD-ARASTIRMA.md` mevcut referans olarak okundu.
