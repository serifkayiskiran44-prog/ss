# Orders and shipment tracking implementation plan

> **For agentic workers:** Execute inline in the assigned implementation task using executing-plans.

**Goal:** Persist and display orders with independently sourced shipment states.
**Architecture:** SQLite JSON snapshots keyed by marketplace/shop/order; manual shipment observations retained across read-only Etsy refreshes. WPF virtualized list with editable local details.
**Tech Stack:** .NET 8 WPF, Microsoft.Data.Sqlite, xUnit.
**Spec:** User request: orders, shipping, in-transit and delivered statuses in the program.

## Global constraints
No marketplace writes. No fake seed data. Etsy completed/shipped never implies delivered. Ozon and Navlungo have no verified tracking integration.
