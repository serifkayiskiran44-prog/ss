# Trendyol Workspace Implementation Plan

> For agentic workers: execute the tasks in order, with tests and review at each boundary. The user explicitly approved implementation in this existing checkout; preserve pre-existing changes.

**Goal:** Adapt the five Entegra Trendyol training workflows into a working WPF workspace with real API contracts, reviewed matching and safe sending.

**Tech Stack:** .NET 8 WPF, Microsoft.Data.Sqlite, System.Text.Json, HttpClient, MSTest.
