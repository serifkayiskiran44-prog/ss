MONOBRIDGE MASAÜSTÜ — .NET 8 WPF
Başlatılacak dosya: Windows\TrMarketplaceHubDesktop.exe
Tarayıcı veya yerel web sunucusu açılmaz. .NET 8 Windows Desktop Runtime gerekir.

Bu sürümde:
- Gerçek Windows penceresi, çalışan menü geçişleri.
- Ürün adı/SKU/barkod araması, stok/hazır durum filtresi.
- Standart XML dosyası seçme ve yerel ürün listesine alma.
- Etsy API key, shared secret, OAuth token ve Shop ID giriş alanları.
- Windows DPAPI ile şifreli kaydetme ve yeniden açılışta yükleme.
- Etsy gerçek mağaza API'sine salt okunur bağlantı testi.
- Önceki XML panelinin pool.db dosyasını salt okunur görüntüleme.
- Salt okunur SQLite sorgu ekranı.

Henüz tamamlanmayanlar:
- Gelişmiş XML URL/alan eşleştirme/fiyat kurallarının masaüstüne taşınması.
- OAuth izin alma ve token yenileme; ürün gönderme; pazaryeri eşleştirme ve sipariş alma.
- eBay/Joom, Navlungo ve Fastfatura.
